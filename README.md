# 🎯 AI Chat Tool

A modern web app that combines an **AI chat interface**, **smart tools**, and an **activity dashboard** — think of it as a mini AI workspace inspired by apps like Notion + chat assistants.

---

## 🚀 Project Goal

Build a web app where users can:

- **Chat with an AI assistant**
- **Use smart tools** (summarizer, notes, code explainer)
- **View activity dashboard** with usage stats

---

## 🛠️ Tech Stack

- React (Vite)
- Tailwind CSS
- React Router
- Context API / useReducer
- Axios / Fetch API
- _(Optional)_ AI API integration (Gemini / OpenAI / Claude)

---

## 🧩 Core Features

### 1️⃣ AI Chat Interface 💬

- Input box for user prompts
- Chat bubbles (user + AI)
- Auto scroll for smooth UX
- Loading animation while AI responds

---

### 2️⃣ Smart Tools Section 🧠

Tools to enhance productivity:

- Text Summarizer
- Notes Generator
- Code Explainer

---

### 3️⃣ Dashboard Overview 📊

- Number of chats
- Tasks completed
- Usage stats

---

### 4️⃣ Sidebar Navigation

Sections:

- Chat
- Tools
- Dashboard
- Settings

---

### 5️⃣ History System

- Save chats locally
- View past conversations
